# hermes-launch
Hermes Field Guide: an independent, practical guide to Hermes Agent for technical newcomers. One static HTML file. Live: https://launch.technoir.cloud

## Commands
- Check (before every commit and deploy): `./scripts/check.sh`
- Deploy: `./scripts/deploy.sh`

## Non-negotiables
1. The official Hermes docs and live model catalogue win; review changes against them before publishing.
2. No credentials, tokens or connection strings in examples; the check fails on credential-like strings.
3. Prices are dated, illustrative snapshots, never guarantees or financial advice.
4. Not official Nous Research documentation; say so.
