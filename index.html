Chapter 01 / preview

What is Hermes Agent?

Hermes is an autonomous AI agent. You give it a goal; it can decide which tools to use, inspect information, change files or run commands, then report what happened.

That makes it different from a chat window. A chat window mainly returns text. An agent can create effects in the world around it. The useful question is not only “which model is smartest?” but also:

  1. Where is the agent running?
  2. Which tools are available?
  3. What permissions does it have?
  4. How will I verify the result?
