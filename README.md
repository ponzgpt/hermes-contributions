# hermes-contributions

What one heavy user built around [Hermes Agent](https://github.com/NousResearch), and is offering back.

Not affiliated with Nous Research. No logos, no endorsement, no claim to have contributed to the project's own code. Everything here was written by someone who uses Hermes Agent daily and kept hitting the same four gaps: getting started, understanding what the CLI actually does, a practical guide for people who are not engineers, and making it useful against a Markdown vault.

| Part | What it is | Came from |
|---|---|---|
| `onboarding/` | The shortest path to a working Hermes Agent, plus a script that names the one next thing to do | `ponzgpt/0th-hermes` |
| `page/` | A page that behaves like the CLI it describes: slash palette, six skins, no build step | `ponzgpt/hermes-agent-site` |
| `field-guide/` | A practical guide for technical newcomers | `ponzgpt/hermes-launch` |
| `pkm-toolkit/` | Skills and a stdio MCP server for local Markdown vaults | `ponzgpt/hermes-pkm-toolkit` |

**This repo is mid-migration.** The four source repos above are still live and still authoritative until each part lands here and its old host redirects. See [AGENTS.md](AGENTS.md).
